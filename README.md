# CleanLocker 🧹⌨️

Минималистичное приложение для блокировки клавиатуры и мыши. Позволяет безопасно протирать периферию, исключая случайные нажатия и действия.

## 🛠 Стек
- C# / .NET
- AvaloniaUI

## 🚀 Быстрый старт
```bash
git clone https://github.com/ExoSeamoth/CleanLocker.git
cd CleanLocker
dotnet run --project CleanLocker
```

## 💡 Как использовать
1. Запустите приложение и активируйте блокировку.
2. Спокойно почистите клавиатуру.
